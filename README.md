# Predictive impedance controller for KINOVA Gen 3 robotic arm

This repository contains the code used during the Imperial's MSc Final project "Adaptive robot that helps you carry heavy objects like a human". It contains a copy of the final MSc report, as well as the key files for the project, organized in different folders:


- Matlab: includes the matlab files for analyzing the trajectories recorded by the KINOVA robot

- Predictive impedance controller: includes the C++ files for the control of the robot in the predictive impedance mode and admittance mode

- ProMP and UKF: includes the C++ files for the offline human trajectory predictor with the ProMP and UKF algorithms

- raw_work: old files from previous version of the project
